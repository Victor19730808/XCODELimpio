1. 📖 Introducción

El Sistema de Menús GV es un framework centralizado para gestionar menús hamburguesa en toda la aplicación de forma consistente, flexible y mantenible.

🎯 Objetivos

  • Centralización: Todas las configuraciones de menú en un solo lugar
  • Simplicidad: Una sola línea de código para implementar un menú completo
  • Flexibilidad: Diferentes tipos de menú según el contexto
  • Mantenibilidad: Fácil de actualizar y extender
  • Consistencia: Misma experiencia de usuario en toda la app

✨ Características Principales

  • 5 tipos de menú predefinidos
  • 4 opciones de menú configurables
  • Navegación automática (Sheet por defecto, Navigation opcional)
  • Integración perfecta con el sistema de Headers
  • Vistas destino configuradas centralmente
  • Sin código repetitivo en las vistas
✅ Ventaja Clave: Una vista solo necesita declarar qué tipo de menú quiere y el sistema maneja TODO automáticamente (estados, sheets, navegación, vistas destino).

  5. Usuario hace click: Menú se despliega

  7. Sheet se activa: Muestra vista destino

4. 🍔 Tipos de Menú

El sistema incluye 5 tipos de menú predefinidos:

Tipo ID Descripción Opciones Icono
.principal 1 Menú completo con todas las opciones 4 opciones (Temas, Admin, Búsquedas, Config) line.3.horizontal
.mapa 2 Menú para vistas de mapas 3 opciones (sin Admin Datos) map
.lista 3 Menú para vistas de listas 3 opciones (sin Búsquedas Avanzadas) list.bullet
.simple 4 Menú minimalista 1 opción (solo Temas) gear
.ninguno 5 Sin menú visible 0 opciones -

💻 Código en GV_MenuType.swift

enum GV_MenuType: Int, CaseIterable, Identifiable { case principal = 1 case mapa = 2 case lista = 3 case simple = 4 case ninguno = 5 var id: Int { self.rawValue } var displayName: String { switch self { case .principal: return "Menú Principal" case .simple: return "Menú Simple" // ... } } }

7. 🧭 Sistema de Navegación

📱 Tipos de Navegación

enum GV_NavigationType { case sheet // Modal con .sheet() - DEFAULT case navigation // NavigationLink - Opcional }

🔄 Cómo Funciona

Tipo Implementación Cuándo Usar
.sheet (Default) .sheet(isPresented: $show) { vista } • Configuraciones
• Opciones de menú
• Acciones rápidas
.navigation NavigationLink(destination: vista) • Flujos principales
• Navegación con historial
• Contenido principal

🎯 Configuración de Navegación

Cada opción de menú define su tipo de navegación:

var navigationType: GV_NavigationType { switch self { case .themes: return .sheet // Modal para temas case .adminDatos: return .sheet // Modal para admin case .advancedSearch: return .sheet // Modal para búsquedas case .mySettings: return .sheet // Modal para configuraciones } }
💡 Nota: Para cambiar a navegación normal, simplemente cambia .sheet por .navigation en la opción correspondiente.

12. 🔗 Integración con Headers

🎯 headerViewWithMenu()

Esta función combina header y menú en una sola llamada:

func headerViewWithMenu( _ caption: String, // Texto del header _ imagen: String? = nil, // Imagen opcional (de Assets) _ menuType: GV_MenuType = .ninguno // Tipo de menú (default: sin menú) ) -> some View

📋 Ejemplos de Uso

Sin menú (default):

myHeader.headerViewWithMenu("Mi Vista", "BF")

Con menú simple:

myHeader.headerViewWithMenu("Mi Vista", "BF", .simple)

Con menú principal:

myHeader.headerViewWithMenu("Mi Vista", "BF", .principal)

Sin imagen, con menú:

myHeader.headerViewWithMenu("Mi Vista", nil, .mapa)

🔍 Qué Hace Internamente

  1. Crea GV_HeaderWithMenuWrapper (view wrapper)
  2. Declara @State variables internas para cada opción
  3. Renderiza el header con imagen, caption y menú
  4. Agrega .sheet() modifiers para cada opción
  5. Conecta cada opción con su vista destino
💡 Ventaja: La vista NO necesita declarar estados ni sheets. Todo es automático.

14. 🔧 Solución de Problemas

❌ Error: "Cannot find 'MenuOption' in scope"

// ❌ Error case .miNuevoTipo: return [.miNuevaOpcion] // MenuOption no existe // ✅ Solución // 1. Agregar primero el caso en MenuOption (línea ~103) enum MenuOption: String { case miNuevaOpcion = "Mi Nueva Opción" // ✨ Agregar aquí primero } // 2. Luego usarla en availableOptions case .miNuevoTipo: return [.miNuevaOpcion] // ✅ Ahora funciona

❌ Error: "Missing argument label 'showThemes:'"

Causa: Estás usando la versión antigua de menuView() con closures.
// ❌ Versión antigua menuType.menuView( onThemes: { print("Temas") } // Ya no existe ) // ✅ Solución: Usar headerViewWithMenu myHeader.headerViewWithMenu("Caption", "BF", .principal) // El sistema maneja todo automáticamente

❌ El menú no se muestra

// ❌ Problema myHeader.headerViewWithMenu("Caption", "BF") // Sin tercer parámetro // ✅ Solución myHeader.headerViewWithMenu("Caption", "BF", .principal) // Con tipo de menú
💡 Explicación: El tercer parámetro tiene default .ninguno, por lo que si no lo pasas, no muestra menú. Pasa explícitamente el tipo que necesitas.

❌ La vista destino no se muestra

Verificar:
  1. ¿Agregaste la opción en MenuOption.destinationView?
  2. ¿Agregaste el caso en menuView() switch?
  3. ¿Agregaste el @State en GV_HeaderWithMenuWrapper?
  4. ¿Agregaste el .sheet() en el wrapper?

❌ Error de compilación en GV_MenuConfig

// ❌ Error: "Missing argument in call" case .miNuevoTipo: return GV_MenuConfig( showMenu: true, // Falta algún parámetro ) // ✅ Solución: Incluir TODOS los parámetros case .miNuevoTipo: return GV_MenuConfig( showMenu: true, // ✅ iconName: "icon", // ✅ iconSize: 22, // ✅ iconColor: .white, // ✅ options: [.themes], // ✅ backgroundColor: .clear, // ✅ padding: 16 // ✅ )

📌 Resumen Rápido

Para usar el sistema:

// 1. Declarar header private let myHeader: GV_HeaderType = .tipo2 // 2. Usar en una sola línea myHeader.headerViewWithMenu("Caption", "Imagen", .tipoMenu)

Para agregar nuevo tipo de menú:

  1. GV_MenuType.swift: Agregar caso + 4 propiedades (displayName, description, availableOptions, icon)
  2. GV_MenuConfig.swift: Agregar configuración visual en getMenuConfig()
  3. Usar: .miNuevoTipo

Para agregar nueva opción:

  1. MenuOption: Agregar caso + icon + navigationType + destinationView
  2. menuView(): Agregar binding + case en switch
  3. Wrapper: Agregar @State + .sheet()
